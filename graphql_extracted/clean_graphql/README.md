# Kinopoisk GraphQL

Реконструированная клиентская GraphQL-схема и набор операций из Android-приложения и веб-клиента Кинопоиска.

## Содержимое

- `schema.graphql` — объединённая client-visible схема.
- `queries/query` — GraphQL-запросы.
- `queries/mutation` — GraphQL-мутации.
- `queries/fragments` — отдельные фрагменты.
- `manifest.json` — источники и SHA-256 документов.
- `report.json` — статистика экспорта.

Все файлы очищены от комментариев и описаний, имеют понятные имена без числовых префиксов и отформатированы с помощью Prettier.

## Статистика

- 316 queries
- 108 mutations
- 35 fragment-документов
- 1 841 тип в схеме
- 5 805 полей

## Проверка форматирования

```bash
npx prettier@3.8.3 --check "**/*.graphql"
```

## Ограничения

Схема восстановлена по операциям клиентов и не является полной серверной схемой. Неиспользуемые клиентами типы и поля в ней отсутствуют, а часть неизвестных типов обозначена как `UnknownScalar` или `UnknownInput`.

Проект предназначен для исследования структуры GraphQL API.
